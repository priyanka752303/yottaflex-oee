# Source manifest and lawful use

| Item | Value |
|---|---|
| External datasets used | **None** |
| Personal or confidential data | None. Plant, line, machine and product names are invented. People appear only as roles (for example `PLANT_OPERATOR`). |
| Data origin | 100% synthetic, generated by `oee/generator.py` |
| Generator version | 1.0.0 (`oee/config.py: GENERATOR_VERSION`) |
| Fixed seed | `20261022` (`oee/config.py: DEFAULT_SEED`) |
| Generator command | `python -m oee run --scale full` (or `--scale starter`) |
| Machine-readable manifest | `out/<scale>/manifest.json` lists every output file with its row count, size and SHA-256, plus the scale parameters, seed and command. The committed copy for the starter dataset is `sample_data/starter/manifest.json`. |

## Schema inspiration

* The OEE definitions (Availability × Performance × Quality) and the "six big losses" classification of stops and minor stops are general, widely published manufacturing practice.
* The Plant → Line → Machine hierarchy loosely follows the ISA-95 equipment hierarchy.
* No text, data or code was copied from any source.

## Dependencies

Only the Python standard library is used: `csv`, `json`, `sqlite3`, `random`, `hashlib`, `unittest` and others.
